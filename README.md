## 📦 Installation

### Prerequisites

- Python 3.x
- pip (Python package manager)

### Quick Start

1. **Clone the repository:**
```bash
git clone https://github.com/its-me-abi/frida_down.git
cd frida_down
```

2. **Install dependencies:**
```bash
pip install -r requirements.txt
```
