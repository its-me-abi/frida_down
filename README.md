# 🔽 frida_down

> A lightweight Frida binaries downloader

## 📋 Prerequisites

- Python 3.x
- pip (Python package manager)

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/its-me-abi/frida_down.git
cd frida_down

# Install dependencies
pip install -r requirements.txt
```
